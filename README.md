# Alper Bulat

I build and run software alone, with a team of AI agents — a one-person
company in Karlsruhe, Germany.

**The rule everything follows:** AI extracts, code calculates, the human
decides. An LLM in my stack is never allowed to invent a price or send an
email. It prepares; deterministic code checks; I approve what leaves the
building.

## What that looks like in practice

- **[offerre](https://offerre.de)** — quoting software for German SMBs.
  Live since April 2026, built and operated solo: FastAPI, React,
  PostgreSQL, Azure OpenAI with EU data residency, GDPR taken seriously
  because my customers have to.
- **[oneOS](https://github.com/alperistic/oneos)** — the operating system of
  a one-person company. Not a framework: the actual file structure, role
  specs, work queue and handoff format I run my company on, extracted as a
  template.
- **[Rechnungsbriefkasten](https://rechnungsbriefkasten.vercel.app)** — a
  free viewer for German e-invoices (XRechnung / ZUGFeRD), because opening
  an e-invoice shouldn't require buying software.

## How I work

Agentic development is my daily production workflow, not a demo — Claude
Code writes most of my code, and every change still goes through review,
tests and a deploy process with health checks and rollback. Current honest
state of my agent team: 13 roles specified, 4 running for real, 0
autonomous. I publish that column instead of hiding it; the gap is the
interesting part.
