# Alper Bulat

Founder of **Late**: a small software company in Karlsruhe, Germany,
run by one person and a team of AI agents.

The rule everything follows: the model extracts, code computes,
a human decides.

## What Late ships

- **[offerre](https://offerre.de)**: quoting software for German SMBs.
  Turns a free-text customer request and a price list into a calculated
  quote draft. Live since April 2026, built and operated solo: FastAPI,
  React, PostgreSQL, Azure OpenAI with EU data residency.
- **[insertcoin.lol](https://insertcoin.lol)**: an arcade where startups
  fight 1:1 in AI-judged matches and build a public win/loss record.
  Scoring is deterministic, in code.

## Open source

- **[evidence-first-doc-pipeline](https://github.com/alperistic/evidence-first-doc-pipeline)**:
  LLM document analysis where every extracted value carries a page number
  and a verbatim quote, verified against the source.
- **[Late OS](https://github.com/alperistic/oneos)**: the operating system
  of a one-person company. Shared memory, agent roles, hard
  human-in-the-loop boundaries.
- **[portfolio](https://github.com/alperistic/portfolio)**: my site, a 360°
